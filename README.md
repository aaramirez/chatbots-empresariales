# Cómo construir chatbots empresariales

Diseñar, construir y operar el chatbot de una empresa de punta a punta: diseño conversacional, tipos de bot y patrón híbrido, canales como WhatsApp y la web, traspaso a humano, pagos seguros en el chat, costo por conversación, métricas, gobierno y el proyecto de implementación.

**Ver en línea:** https://aaramirez.github.io/chatbots-empresariales/

Este repositorio solo tiene el sitio generado. Curso completo: 17 capítulos con laboratorios interactivos, diagramas y prácticas.
